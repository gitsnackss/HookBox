HookBox - Webhook Inbox & Replay

Capture, inspect, and replay webhooks with ease.

API Documentation

Interactive API Docs: Swagger UI | ReDoc

Quick Start

  1. Set your ADMIN_API_KEY_HASH in .env
  2. Run python scripts/init_db.py to create your first project
  3. Use the generated API key and inbox key

Core Endpoints

  • POST /i/{project_key} - Ingest webhook
  • GET /api/v1/projects/{id}/webhooks - List webhooks (requires auth)
  • GET /api/v1/webhooks/{id} - Get webhook detail (requires auth)
  • POST /api/v1/webhooks/{id}/replay - Replay webhook (requires auth)
  • POST /api/v1/projects - Create project (requires admin key)

Auth: Use Authorization: Bearer <api_key> header for all protected endpoints.
