# Contributing to HookBox

We welcome contributions!

## Development Setup

1. Fork and clone.
2. Install deps: `pip install -r requirements.txt`.
3. Install dev deps: `pip install pytest ruff black mypy`.
4. Run tests: `pytest`.

## Code Style

- **Formatting**: `black` (line length 100)
- **Linting**: `ruff`
- **Type Checking**: `mypy`

Please ensure all check pass before submitting a PR.
